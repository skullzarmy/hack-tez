# ICO Commitments

In 2017 the Tezos fundraiser created a fixed list of commitments, fixed at genesis. Each holds a balance until its owner activates it with a secret code. Activation moves the balance to a normal tz1 account. It does not mint new tez. The list is finite and public, so anyone can verify an activation.
